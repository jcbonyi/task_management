# Insurance Compliance Task Manager

A lightweight single-page task management app designed for insurance agency compliance officers.

## Features
- Create compliance tasks with due dates, category, owner, and regulatory references.
- Track statuses (`Open`, `In Progress`, `Blocked`, `Completed`) with one-click advancement.
- Filter tasks by status.
- View summary chips for total, overdue, high-priority, and completed tasks.
- Data is persisted in browser `localStorage`.

## Run locally
```bash
python -m http.server 4173
```
Then visit `http://localhost:4173`.
